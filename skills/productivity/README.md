# Productivity

Allgemeine Workflow-Tools, nicht code-spezifisch.

- **[caveman](./caveman/SKILL.md)** — Ultra-komprimierter Kommunikationsmodus. Senkt Token-Verbrauch um ~75%, indem Füllwörter wegfallen, aber die volle technische Genauigkeit bleibt.
- **[grill-me](./grill-me/SKILL.md)** — Werde unerbittlich zu einem Plan oder Design befragt, bis jeder Zweig des Decision Trees aufgelöst ist.
- **[handoff](./handoff/SKILL.md)** — Die aktuelle Konversation in ein Handoff-Dokument komprimieren, damit ein anderer Agent die Arbeit fortsetzen kann.
- **[write-a-skill](./write-a-skill/SKILL.md)** — Neue Skills mit richtiger Struktur, Progressive Disclosure und gebündelten Ressourcen erstellen.
